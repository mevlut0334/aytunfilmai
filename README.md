# Aytun Film AI

Laravel tabanlı yapay zeka destekli film oluşturma platformu.

## 🚀 Özellikler

- 🎬 AI ile video oluşturma
- 💳 Havale ile ödeme sistemi
- 🖼️ Dinamik içerik yönetimi
- 🔐 Güvenli admin paneli
- 📱 Responsive tasarım

## 🛠️ Teknolojiler

- Laravel 11
- PHP 8.2
- MySQL 8.0
- Docker
- Nginx
- SSL (Let's Encrypt)

## 📦 Kurulum

Detaylı kurulum talimatları için [SKILL.md](SKILL.md) dosyasına bakın.

### Hızlı Başlangıç
```bash
# Repository'yi klonla
git clone https://github.com/KULLANICI_ADI/aytunfilmai.git
cd aytunfilmai

# SSL ile deploy et
chmod +x deploy-ssl.sh
./deploy-ssl.sh
```
